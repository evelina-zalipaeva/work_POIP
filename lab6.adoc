== Теоретическая часть

=== Настройка портов GPIO
Для работы с периферией использовались следующие регистры:
* *GPIOx_MODER*: выбор режима работы пина (вход/выход/альтернативная функция).
* *GPIOx_PUPDR*: настройка подтягивающих резисторов (подтяжка к питанию/земле/без резистора).
* *GPIOx_IDR*: чтение состояния входного сигнала (для кнопки).
* *GPIOx_ODR*: установка уровня на выходных пинах (для светодиодов).

=== Принцип инверсии зависимостей (DIP)
- Созданы абстракции для управления светодиодами и кнопкой.
- Основная логика приложения зависит только от интерфейсов, а не от конкретной реализации.

== Практическая часть

=== Настройка светодиодов и кнопки
1. *Светодиоды*: 
   - Настроены как выходы (GPIO_MODE_OUTPUT_PP).
   - Скорость: GPIO_SPEED_FREQ_LOW (через GPIOx_OSPEEDR).
   - Подтяжка отключена (GPIO_NOPULL).

2. *Кнопка*:
   - Настроена как вход с подтяжкой к питанию (GPIO_MODE_INPUT + GPIO_PULLUP).
   - Использован регистр GPIOx_IDR для чтения состояния.

=== Реализация переключения режимов
[source,c]
----
// Абстракция для кнопки
typedef struct {
    bool (*is_pressed)(void);
} Button_Interface;

// Абстракция для светодиодов
typedef struct {
    void (*set_mode)(uint8_t mode);
} LED_Controller;

// Пример обработки нажатия кнопки
void handle_button_press(Button_Interface btn, LED_Controller leds) {
    static uint8_t current_mode = 0;
    if (btn.is_pressed()) {
        current_mode = (current_mode + 1) % 4; // 4 режима
        leds.set_mode(current_mode);
        while (btn.is_pressed()); // Дребезг
    }
}

// Реализация для STM32
bool stm32_button_is_pressed(void) {
    return (GPIOA->IDR & (1 << BUTTON_PIN)) == 0; // Кнопка подключена к земле
}
----

            HAL_GPIO_TogglePin(LED_PORT, LED_PIN);
            HAL_Delay(500);
            break;
        case 1: // Бегущая волна
            // Логика анимации
            break;
        case 2: // ШИМ-режим
            // Управление яркостью
            break;
        case 3: // Аварийный сигнал

== Сложности и решения
1. *Дребезг кнопки*: Реализована программная задержка после нажатия.
2. *Конфликт регистров*: Проверка корректности настройки GPIOx_MODER для каждого пина.
3. *Оптимизация скорости*: Использование битовых операций для быстрого доступа к регистрам.
