== Введение в ОСРВ
=== Определение
ОСРВ (Операционная Система Реального Времени) — система, гарантирующая выполнение задач в строго заданные временные рамки.  
Основные характеристики:
* Детерминированность (предсказуемое время отклика)
* Поддержка многозадачности
* Управление ресурсами (память, процессорное время)

== Принцип работы ОСРВ
=== Основные компоненты
1. *Диспетчер задач*: Распределяет процессорное время между задачами.
2. *Межзадачная коммуникация*: Семафоры, мьютексы, очереди.
3. *Таймеры и планировщик*: Обеспечивают временные ограничения.

=== Состояния задач
[cols="1,3", options="header"]
|===
| Состояние | Описание
| *READY* | Задача готова к выполнению, но не активна
| *RUN* | Задача выполняется на процессоре
| *WAIT* | Задача ожидает события (таймер, семафор и т.д.)
| *SUSPEND* | Задача приостановлена вручную (не участвует в планировании)
|===

== Работа с задачами в FreeRTOS
=== Приоритеты задач
* Приоритет задается при создании задачи (0 — минимальный, configMAX_PRIORITIES-1 — максимальный).
* Если несколько задач в состоянии READY, выполняется задача с *наивысшим приоритетом*.
* Пример изменения приоритета:
[source,c]
----
vTaskPrioritySet(taskHandle, newPriority); // Изменение приоритета "на лету"
----

=== Состояние SUSPEND
* Задача приостанавливается через API:
[source,c]
----
vTaskSuspend(taskHandle); // Приостановка
vTaskResume(taskHandle);  // Возобновление
----
* Причины перехода в SUSPEND: 
  - Ручная приостановка
  - Ожидание внешнего события (активация семафором/мьютексом).

=== Задача IDLE
* Выполняется, когда нет активных задач в состоянии READY.
* Возможности:
  - Режим энергосбережения:
[source,c]
----
void vApplicationIdleHook(void) {
    enterLowPowerMode(); // Пользовательская callback-функция
}
----
  - Расчет загрузки процессора.

== Межзадачное взаимодействие
Основные инструменты:
* *Семафоры*: Синхронизация задач (например, ожидание данных от UART).
* *Мьютексы*: Защита общих ресурсов (например, доступ к SD-карте).
* *Очереди*: Передача сообщений между задачами.

Пример использования бинарного семафора:
[source,c]
----
SemaphoreHandle_t xSemaphore = xSemaphoreCreateBinary();

// Задача 1: Ожидание семафора
xSemaphoreTake(xSemaphore, portMAX_DELAY);

// Задача 2: Активация семафора
xSemaphoreGive(xSemaphore);
----
