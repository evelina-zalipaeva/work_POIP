== Программирование режимов работы светодиодов

=== Настройка GPIO
1. С помощью STM32CubeMX настроила вывод GPIO (например, PC13) в режиме выхода (Output)
2. Использовала HAL-библиотеки для управления светодиодом:

[source,c]
----
// Инициализация
HAL_GPIO_WritePin(GPIOC, GPIO_PIN_13, GPIO_PIN_RESET);

// Включение/выключение
HAL_GPIO_TogglePin(GPIOC, GPIO_PIN_13);
HAL_Delay(500); // Задержка 500 мс
----

=== Режимы работы
* *Мигание*: Простейший цикл с задержкой
* *Дыхание*: Использовала ШИМ (PWM) через таймер:

[source,c]
----
// Настройка таймера (например, TIM2)
HAL_TIM_PWM_Start(&htim2, TIM_CHANNEL_1);
__HAL_TIM_SET_COMPARE(&htim2, TIM_CHANNEL_1, brightness);
----

* *Последовательности*: Реализовала паттерны через конечный автомат:

[source,c]
----
typedef enum {
    PATTERN_OFF,
    PATTERN_BLINK,
    PATTERN_FADE
} LedMode;

LedMode current_mode = PATTERN_BLINK;
----

== Визуализация структуры кода в PlantUML
Для организации кода создала диаграммы, которые показывают взаимодействие модулей.

=== Пример диаграммы классов
[plantuml,test-diagram,png]
----
@startuml
class Main {
  + void main()
}

class LedController {
  - uint32_t pin
  + void toggle()
  + void setBrightness(uint8_t value)
}

Main --> LedController : использует
@enduml
----

=== Описание элементов
* `Main`: Главная программа, запускает логику
* `LedController`: Класс для управления светодиодом
