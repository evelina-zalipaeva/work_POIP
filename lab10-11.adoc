== Введение

Целью практики являлось изучение работы с микроконтроллерами семейства STM32, включая их архитектуру, типы данных, регистры, а также работу с аналого-цифровыми преобразователями (АЦП).

Основные задачи:
* Изучение встроенных типов данных C++ и их модификаторов
* Работа с регистрами микроконтроллера
* Настройка цифровых входов/выходов
* Работа с АЦП, включая измерение температуры встроенного датчика

== Основная часть

=== Типы данных в C++

В процессе работы были изучены встроенные типы данных C++ и их модификаторы. Для обеспечения портируемости проекта рекомендуется использовать псевдонимы типов:

* `std::uint32_t` - для 32-битных беззнаковых целых чисел
* `std::int64_t` - для 64-битных знаковых целых чисел
* `std::uint8_t` - для 8-битных беззнаковых целых чисел

=== Регистры микроконтроллера

Изучены специальные регистры микроконтроллера STM32F411:

* R13/SP (указатель стека)
* R15/PC (программный счетчик)
* R14/LR (регистр связи, хранит адрес возврата)

Особое внимание уделено сохранению и восстановлению вспомогательных регистров (R4-R11) при работе с функциями.

=== Цифровые входы и выходы

Настроены цифровые входы и выходы микроконтроллера:

* В режиме цифрового выхода порт может находиться:
  ** В состоянии High (подключен к питанию)
  ** В состоянии Low (подключен к земле)
* В режиме цифрового входа порт имеет высокое сопротивление, что может приводить к "плавающим" значениям

=== Работа с АЦП

Основные характеристики АЦП:

* Разрешение (6, 8, 10 или 12 бит)
* Частота дискретизации
* Режимы работы:
  ** Одиночное преобразование
  ** Сканирование
  ** Непрерывное измерение

Для АЦП микроконтроллера STM32F411:

* Преобразование выполняется методом последовательного приближения
* Время преобразования зависит от:
  ** Частоты тактирования
  ** Времени дискретизации

=== Измерение температуры

Выполнено задание по измерению температуры:

1. Настроен канал АЦП для работы с датчиком температуры
2. Запущено одиночное преобразование
3. Считано значение температуры из регистра ADC-DR

== Заключение

В ходе практики получены навыки работы с микроконтроллерами STM32, включая:

* Использование правильных типов данных
* Настройку регистров
* Управление цифровыми входами/выходами
* Работу с АЦП

Результаты могут быть применены в дальнейших проектах.
